# 模拟投资账户 · Android / 离线版

版本 0.2.0（v32）。用历史行情练习账户、交易、现金流和资产配置。默认初始资金为 10 万元，可在“我的”修改。账户保存在本机，不连接真实银行或券商。

## 使用

Android 安装交付的调试 APK 后打开即可离线使用，无需账号或付费数据。网页预览在本目录运行 npm run start，再在当前电脑打开 http://127.0.0.1:4174/ 。本地服务器只监听当前电脑，不会自动开放局域网。

底部导航：首页、行情、交易、持仓、我的。首页推进下一个交易日或回退；行情和交易页查看价格与规则，再提交委托；持仓查看现金流；“我的 → 资产分析”查看收益与知识要点。Android 导出通过系统文件保存窗口选择位置。

## 默认历史数据

回放为 2020-01-02 至 2020-06-30，共 117 个交易日：

- 招商银行 600036：117 条不复权日线，含开高低收及成交量。
- 易方达蓝筹精选混合 005827：117 条公布单位净值，保留暂停申购/赎回状态。
- 中国银行活期存款：当时挂牌年利率 0.30%，此半年无调整；按自然日/360计提、按季结息，支持每月自动转入。
- 国债：明确标注的记账式债券教学例子，包含净价、应计利息、全价和固定票息。尚未替换为真实国债历史行情。
- 开店与创业融资退出：经营情景，不代表真实企业历史。

来源、下载时间、原始记录摘要和许可状态见 data/source-manifest.json 及 data/research/SOURCES_RESEARCH.md。公开取得的数据没有被标成“已获再分发授权”。当前用途为本机个人学习；公开分发或商业使用须另行核验来源许可。本次未购买任何数据。

## 交易模型

股票使用日频收盘价撮合教学模型，不模拟盘中限价排队、涨跌停队列或撮合滑点。支持 100 股整手、T+1可卖；佣金默认万3最低5元，可在“我的”调整，过户费与卖出印花税单列。

基金收盘后提交，以下一估值日公布 NAV 确认，赎回再下一交易日到账（简化 T+2）。公布净值已内扣管理/托管费，不会再次扣份额。申购0.15%、赎回0.50%为教学渠道假设，尚未按该基金2020年合同及持有期完整配置。

每类金融资产当前使用一个标的槽，默认提供上述教学样本，不代表当年完整可投资市场。导入与现有证券代码不同的记录会被拦截，避免混接价格曲线。开店、融资、失败和退出按情景参数触发。
